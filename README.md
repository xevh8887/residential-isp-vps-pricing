## 原生IP、住宅IP、双ISP：三个常被混用的词

原生IP指 IP 的注册地和机房物理位置一致，洛杉矶机房的 IP 在 WHOIS 里国家也是美国。住宅IP指这个 IP 被分配给家庭宽带用户，归属 ASN 是 Comcast、AT&T 这类民用宽带运营商，而非 Linode、Vultr 这类 IDC 运营商。TikTok、亚马逊、Netflix、ChatGPT 做风控时会查 ASN 归属，机房地址段容易被判定为“非真人流量”。

双ISP 指的是同一个 IP 在两个不同民用 ISP 名下都有注册记录，不是给你两个 IPv4。丽萨主机所有套餐默认只给 1 个 IPv4，要多 IP 需单独加购。双ISP 的实际作用是留后路：一个 ISP 的段被某平台批量标记时，另一个段还能用。
